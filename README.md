# Toss V4 Trader

무한매수법 V4용 개인 자동매매 대시보드 초안입니다.

## 현재 구현
- TQQQ / SOXL, 20/40분할
- NORMAL: 첫 매수 / 전반전 / 후반전
- 별지점, 1회 매수금, 쿼터 LOC 매도, 목표 지정가 매도
- REVERSE: T >= N-1 진입, 첫날 MOC 매도, 이후 LOC 매도 + 잔금 1/4 LOC 매수 구조
- TQQQ -15% / SOXL -20% 회복선 표시
- 자동매매 ON/OFF 및 긴급중지 UI
- 토스증권 현재가 API 서버 연결 예제
- 기본 LIVE 주문 차단

## 실행
### 권장: 로컬 보안 서버
Node.js 18 이상이 설치된 환경에서 실행합니다.

```bash
node server.js
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 서버는 외부에 공개하지 않고 `127.0.0.1`에만 바인딩됩니다.

### 토스증권 API 연결
1. 토스증권 WTS의 **설정 → Open API**에서 `client_id`, `client_secret`을 발급합니다.
2. 같은 화면의 **허용 IP 관리**에서 이 PC의 공인 IP를 등록합니다.
3. 대시보드의 **API 연결 설정**에서 ID와 시크릿을 입력하고 **로컬에 저장**합니다.
4. **연결 테스트**를 눌러 토큰 발급, 계좌 목록, TQQQ 시세 조회를 확인합니다. 이 단계에서는 주문을 보내지 않습니다.
5. 여러 계좌가 있다면 테스트 결과의 `accountSeq`를 입력한 뒤 다시 저장합니다.

클라이언트 시크릿은 `%LOCALAPPDATA%\TossV4Trader\settings.json`에 저장되며 이 파일은 저장소 바깥에 있어 GitHub에 올라가지 않습니다. Windows DPAPI(CurrentUser)를 사용할 수 있는 환경에서는 암호화해 저장합니다. 현재 실행 환경에서 DPAPI를 사용할 수 없으면 앱이 화면에 **암호화 미사용**으로 표시하며, 이 경우 파일 접근 권한이 있는 로컬 사용자에게 시크릿이 노출될 수 있으므로 전용 PC에서만 사용하세요. 액세스 토큰은 메모리에만 보관하고 디스크에 저장하지 않습니다.

### 실주문 안전장치
- 실주문 전송은 기본값이 꺼져 있습니다.
- API 설정에서 명시적으로 켠 뒤에도 주문표의 **실주문** 버튼을 눌러야 합니다.
- 전송 직전 표시되는 종목·방향·수량·가격을 확인하고 `LIVE ORDER` 문구를 입력해야 합니다.
- 서버는 주문마다 새 멱등성 키(`clientOrderId`)를 생성합니다.
- 자동매매 스위치는 현재 주문표 계산용이며, 자동으로 주문을 보내지 않습니다.

## 중요
실제 주문은 시장 변동에 따라 손실이 발생할 수 있습니다. LOC는 미국 주식 `LIMIT + CLS` 조합으로 전송되며, MOC는 현재 이 앱에서 실주문으로 전송하지 않습니다. 주문 접수 결과와 체결 상태는 반드시 토스증권 주문내역에서 확인하세요.

클라이언트 시크릿, 액세스 토큰, 계좌번호를 HTML/JavaScript 또는 GitHub에 넣지 마세요.
