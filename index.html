토스증권 API 연결

클라이언트 시크릿은 이 브라우저나 GitHub에 저장되지 않습니다. 이 PC의 로컬 설정 파일에만 저장되며, Windows DPAPI를 사용할 수 있으면 현재 사용자 계정으로 암호화합니다. 저장 결과의 보안 상태는 아래에 표시됩니다.
시작 전 토스증권 WTS의 설정 → Open API에서 키를 발급하고, 이 PC의 공인 IP를 허용 IP 목록에 등록해야 합니다. 연결 테스트는 토큰 발급, 계좌 목록 및 TQQQ 현재가 조회만 하며 주문을 보내지 않습니다.
